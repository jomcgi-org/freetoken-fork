### Deferred and deviations

- Persistent MTP prompt KV and QSA cache. The draft layer currently attends over the current three-token speculative chain only. Verification is lossless, but acceptance may be lower.
- CUDA graphs while MTP is enabled. Graph capture is disabled because graph replay does not expose the target HC hidden state needed by the next draft step.
- Batch size greater than one, non-greedy speculation, and TP greater than one. Larger/non-greedy batches use ordinary decoding; TP greater than one is rejected at startup.
- Full Engine/Scheduler CUDA end-to-end execution. The added CUDA-gated test uses a tiny synthetic target and imperfect draft loop, but no CUDA host was available.
- No runtime acceptance rate was observed for the same reason.

The checkpoint’s stacked BF16 MTP expert tensors alone occupy about 4.69 GiB, materially above the estimated 2 GiB. FTW conversion therefore stores them only when `ft checkpoint --speculative-mtp on` is explicitly selected.

The pre-existing untracked `.codex-dispatch/` directory was not modified.
